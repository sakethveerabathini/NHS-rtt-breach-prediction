# Power BI Dashboard   NHS RTT Breach Prediction

This dashboard visualizes predicted RTT breach risks for April 2025 using machine learning outputs generated in Orange.

## Key Metrics
- Total Pathways
- Predicted Breaches
- Breach Rate

## Visual Insights
- RTT Breach Risk Distribution
- Top Risky Treatment Functions
- Provider-Level Breach Analysis
- Waiting List vs Performance Drivers

## Purpose
The dashboard helps identify high-risk NHS treatment pathways and supports proactive operational planning.
