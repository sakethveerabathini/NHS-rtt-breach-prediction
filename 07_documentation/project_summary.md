# NHS RTT Breach Prediction Project

This project predicts NHS RTT pathway breaches using historical NHS England waiting time data.

## Technologies Used
- Python
- SQL Server
- Orange Data Mining
- Power BI

## Workflow
1. Data collection from NHS England
2. Data preparation using Python
3. SQL cleaning and feature engineering
4. Machine learning prediction using Orange
5. Dashboard visualization using Power BI

## Business Objective
Identify high-risk NHS treatment pathways before breaches occur to support proactive healthcare planning.
